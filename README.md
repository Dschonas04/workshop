# Workshops

[![Lizenz: CC BY-SA 4.0](https://img.shields.io/badge/Lizenz-CC%20BY--SA%204.0-lightgrey.svg)](LICENSE)
[![Code: MIT](https://img.shields.io/badge/Code-MIT-blue.svg)](LICENSE-CODE)

Workshops zum Selbstlernen, auf Deutsch. Jeder Workshop besteht aus Leveln mit
Theorie, Aufgabe und einem Prüfer, der nach jeder Aufgabe sagt, ob sie stimmt.
Musterlösungen liegen jeweils unter `Loesungen/`.

| Workshop | Inhalt | Prüfung |
| -------- | ------ | ------- |
| [Ansible](ansible/) | Ansible in vier Leveln, gegen die eigene Maschine | [![Ansible](https://github.com/Dschonas04/workshop/actions/workflows/ansible.yml/badge.svg)](https://github.com/Dschonas04/workshop/actions/workflows/ansible.yml) |
| [Container](container/) | Docker, Compose und Podman in fünf Leveln | [![Container](https://github.com/Dschonas04/workshop/actions/workflows/container.yml/badge.svg)](https://github.com/Dschonas04/workshop/actions/workflows/container.yml) |
| [Go](go/) | Go in vier Leveln, geprüft von `go test -race` | [![Go](https://github.com/Dschonas04/workshop/actions/workflows/go.yml/badge.svg)](https://github.com/Dschonas04/workshop/actions/workflows/go.yml) |
| [PowerShell](powershell/) | PowerShell von null in neun Leveln | [![PowerShell](https://github.com/Dschonas04/workshop/actions/workflows/powershell.yml/badge.svg)](https://github.com/Dschonas04/workshop/actions/workflows/powershell.yml) |
| [React](react/) | React in vier Leveln, geprüft von Vitest und TypeScript | [![React](https://github.com/Dschonas04/workshop/actions/workflows/react.yml/badge.svg)](https://github.com/Dschonas04/workshop/actions/workflows/react.yml) |
| [Shell](shell/) | Bash Schritt für Schritt in fünf Leveln | [![Shell](https://github.com/Dschonas04/workshop/actions/workflows/shell.yml/badge.svg)](https://github.com/Dschonas04/workshop/actions/workflows/shell.yml) |
| [Terraform](terraform/) | Terraform und OpenTofu in vier Leveln, ohne Cloud-Konto | [![Terraform](https://github.com/Dschonas04/workshop/actions/workflows/terraform.yml/badge.svg)](https://github.com/Dschonas04/workshop/actions/workflows/terraform.yml) |

## Los geht es

```bash
git clone https://github.com/Dschonas04/workshop.git
cd workshop/<workshop>
```

Danach steht im README des jeweiligen Workshops, wie es weitergeht.
